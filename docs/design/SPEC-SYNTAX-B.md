## 0. 这五条为什么是 B 档

A 档的标准是「精度接近 100% 或误报极低」；B 档是「判据成立，但阈值依赖
语料，需要先测再定」。这五条在四份真实语料上都不是零命中，或用密度、
或依赖小词表、或依赖「是否已展开」的启发式，因此先按 B 档落地，并把
读数写死。

## 1. `NOMINALIZATION_RATE`（英文，密度）

### 1.1 判定

1. 只数正文里的英文词（`[A-Za-z][A-Za-z0-9'’\-]*`），词长 `>= 5`；
2. 词形以八个后缀之一结尾：`tion / sion / ment / ance / ence / ity /
   ness / ism`；
3. 先剥离本文出现频次最高的 **5 个类型**（当作领域术语；同频按词面
   字典序），余下的才算分子；
4. `rate = 保留数 × 100 / 英文词总数`，阈值 `4.5`，`>` 触发。

后缀**不含裸 `-al / -ic / -ive`**：`several / partial / beneficial` 会
大面积误命中（B 计划 §四已列为不采纳）。

### 1.2 为什么要剥离 5 个类型

Sword 的 6% 裸线会误伤术语密集论文：`section / instance / evidence /
harness / direction` 这类词在计算机论文里既不是「动作藏在名词里」，也
无法避免。剥离本文最高频的 5 个类型，等价于把领域术语当作已知量，再
看剩下的名词化是否仍然过密。**报的时候必须列出被剥离的 5 个词**，否则
读者无法复查：JSON 在 `metric_details.nominalization_stripped`，人读
报告在指标表下方单列一行，每条 finding 的改法里也写明。

### 1.3 单位

单位＝**每百词百分数**（Sword 口径）：`4.5` 表示每 100 个英文词里 4.5
个名词化词形。不是每千词。阈值与单位在 `style-rules.toml` 的
`[thresholds] nominalization_rate` 与 `[nominalization]` 写死。

### 1.4 误报边界

- 中文语料里零星的英文术语：分子分母都只数英文词；剥离高频类型后通常
  为 0（`paper-b-zh` 实测 0）。
- 同一术语多次出现只算一个类型；剥离按类型而不是按出现次数。
- 缩写、公式、代码块、文献表沿用 `style` 既有遮罩，不参与统计。

## 2. `ZH_ASPECT_ZHE`（中文，密度）

### 2.1 判定

用 `factscribe/segment.py` 分词后，只数两种「动词＋着」：

1. 单独一个「着」紧跟在一个动词后（`存在/着`、`进行/着`、`保持/着`）；
2. 整词以「着」结尾且词性是动词（`有着`、`带着`、`留着`）。

词内用法不走进行体，进 `[zh_aspect_zhe].exclude`：`意味着 / 沿着 /
照着 / 接着 / 随着 / 跟着 / 当着 / 为着 / 够得着` 等。注意 `意味着`
在分词表里是一个整词（v），只靠「动词＋着」会把它算进来，所以必须有
排除表。

### 2.2 单位

单位＝**每千个汉字**（不是每千词）：`hits × 1000 / 汉字数`，阈值
`0.8`，`>` 触发。汉字只数 CJK 区段，标点、数字、拉丁字母不计。

### 2.3 误报边界

- 真正在进行中的动作（`他正看着屏幕`）也被计入分子，这是有意的：
  规则只给密度信号，不逐句判「该不该用进行体」；密度不过线就不报。
- 词内「着」全部排除，`沿着 / 照着 / 接着` 不会推高密度。
- 密度过线后逐条列出命中句，由人判断哪几处改成「了/过」或直接删。

## 3. `ZH_DANG_WHEN`（中文，按条）

### 3.1 判定

同句内匹配：

```
当 +（1–30 字，不含 。！？；：）+（的时候 | 之后 | 时）
```

「时」后面不能是「候」（否则是「什么时候」）。「当」后紧跟
`成/作/然/即/初/场/时/天/年/月/日/前/中/下/上/面/真/众/地/晚/夜/早/代/今`
时是词内用法（`当成 / 当作 / 当然 / 当天 / 当时`），不算条件。

### 3.2 报告内容

每条给删法：

- `当……的时候 / 当……时`：删「当」和尾巴，让条件自己站住；
- `当……之后`：只删「当」，保留「……之后」。

按条报，**不设密度闸**（`>= 1` 触发）。四份语料实测 1 处，在
`paper-zh`，复核为真阳性（见实施记录 §3.3）。

### 3.3 误报边界

- 冒号、分号、句号、问号、感叹号会切断匹配：`当文档：……什么时候跑`
  不再跨标点误连。
- 前置条件（`如果/若` 开头）不是本规则，归 `ZH_POSTPOSED_CONDITION`
  的负例面。
- `当……时` 是正常中文条件句，本规则报的是「可以删掉当/时」的冗余，
  不是语法错。

## 4. `ZH_COLLOCATION_REDUNDANCY`（中文，按条）

### 4.1 词表

| 匹配 | 冗余在哪 | 删法 |
|---|---|---|
| `大约…左右`（同句 0–20 字内） | 「大约」与「左右」都表约数 | 留一个 |
| `唯一一个` | 「唯一」已含「一个」 | 删「一个」 |
| `相互之间` | 「相互」与「之间」叠义 | 删「相互」 |
| `彼此互相` | 两个词同义 | 留一个 |
| `提前预…`（预支/预订/预约…） | 「提前」与「预」叠义 | 删「提前」 |
| `免费赠送` | 「赠送」本身即免费 | 删「免费」 |
| `亲眼目睹` | 「目睹」即亲眼看见 | 删「亲眼」 |
| `再次重申` | 「重申」即再次申明 | 删「再次」 |
| `一致公认` | 「公认」即一致认为 | 删「一致」 |
| `首先第一` | 两个序数词叠用 | 留一个 |

### 4.2 单位与报告

单位＝**处**，`>= 1` 触发；每条 finding 必须带 `fix`（删法），不只报
「这里有冗余」。词表与删法在 `[zh_collocation_redundancy.items]`，可增删。

### 4.3 误报边界

- `大约…左右` 只在同一句内匹配；跨句（`大约三成。左右两栏…`）不报。
- 单一半词不报：`大约三次`、`唯一的一条`、`相互依赖`、`提前到达`、
  `免费提供`、`亲眼看到`、`再次说明`、`一致同意`、`第一步` 都不在表内。
- 四份语料实测 **0 处**：这是「防回归」型词表，不是日常高频。

## 5. `ABBREV_FIRST_USE`（缩写首现，默认关闭）

### 5.1 判定

1. 英文缩写形态：`\b[A-Z]{2,}\b`；罗马数字（`II/III/IV…`）与
   `TODO/TBD/FIXME` 进排除表；
2. 首次出现（按分析顺序，全篇只报一次）时，**同句或前一句**必须出现
   `全称 (ABC)` 或 `全称（ABC）`（半角/全角括号均可）；
3. 找不到展开即报，按条计，`>= 1` 触发。

### 5.2 默认关闭

顶层开关 `abbrev_first_use = false`。只由 `style --report-abbrev` 打开；
打开后进 findings。理由不是「判据不成立」，而是**误报预算**：四份语料
在打开状态下共 13 处，每份 3.1–5.0 处/万字，全部超过准入单的
「每万字 ≤ 2 处」；其中 `SWE / RULER` 是基准专名，不是待展开的缩写。
按准入单第 1 条，超预算就降级，不硬调阈值。

### 5.3 误报边界

- 只查首现，后文重复不再报；同一缩写全篇最多一条。
- 展开必须在同句或紧邻前一句；隔一句再展开视为未展开。
- 专名（基准名、模型名）与通用缩写（PDF/OCR/CV）无法机械区分，这是
  默认关闭的另一半理由。

## 8. 明确不判（防止回填）

- 不做「全文『着』密度」：只数动词后「着」，词内用法排除；
- 不做「全文名词化裸线」：必须先剥离本文前 5 个高频类型；
- 不按 `-al / -ic / -ive` 判名词化；
- 不把 `当……时` 判成语法错：它是可删的冗余，不是错句；
- 不自动改正文：五条都只给黄牌与改法。
