# FactScribe 能证明什么

这份文档只回答一个问题：**看到一条读数，你能说什么，不能说什么。**

## 一句话

它证明的是「账、据、文三者自洽，且据未被改」。
它不证明「论文为真」。

## 能证明的五件事

1. **数字有出处**：正文里每个数字都能回到一条事实，每条事实都钉住一份算过 sha256、且在**人签清单**里的原始产物。
2. **引用落得下**：每个引用命令都指向 `refs.bib` 里存在的条目，条目带 `arxiv` 或 `doi`。
3. **改写没动硬的东西**：`protect` 比对改写前后的 `\fact{}`、数字、引用、公式、表格行、交叉引用，任何变动即红。
4. **改写没引入新病**：`style --diff` 只报「改前没有、改后有」的退化，包含首句复述标题、标题丢对比对象、关系词被替换这类。
5. **一次改动可闭合**：`tide` 要求涨落配对、哈希对得上、波及面全绿；任一不成立，整次回退，不落账。

## 不能证明的五件事

1. **结论为真**：账可以自洽而结论错误。工具只保证「你说的数和你的材料对得上」。
2. **文章更好**：文风规则查的是可机械判定的退化痕迹，不是质量。黄牌少不等于文章好。
3. **符合期刊口味**：不同刊、不同审稿人的偏好互相冲突，工具不替你选。
4. **原创性**：不做查重，不判断是否抄袭。
5. **审稿人喜欢**：没有任何读数能预测这个。

## 引用读数的三条禁令

1. **不许说「审计绿 = 论文没问题」。**
   正确说法：「在 v1.3.0、默认配置下，该项目的审计为 0 红 1 黄。」
2. **不许把盲评胜率当质量结论。**
   「新版赢 69%」是「在某个问法、某群评委、某个呈现顺序下的偏好」。同一批文本换一种问法，结论可以从「旧版赢」翻成「新版赢」——我们实测过。
3. **不许把黄牌数量当分数排名。**
   黄牌是提示，不是评分。把 42 条降到 17 条，意思是「触发项变少」，不是「文章变好 25 分」。

## 为什么会这样：两个实测例子

**例一：问法决定结论。**
同一批 20 组改写稿。
- 问「哪版更像论文」：两位评审一致 16/20，多数选旧版。
- 换成「限定体裁 + 清楚/专业分开打分」：新版胜率 71.7%。
- 再换一个模型重跑：原标签 64.3%，标签对调后 47.5%。

三次问法，三个结论。**文本没变。**

**例二：一致不等于有效。**
D 席三个评审的 κ 一度到 1.000，看起来「非常可靠」；但把 A/B 标签对调，胜率掉了 16.8 个百分点。这正是文献里说的「高稳定与强位置偏好并存」。所以 κ 只能说明「彼此一致」，不能说明「判得对」。

## 正确的引用句式

> 在 FactScribe v1.3.0、默认配置、样本 N 下：审计 0 红 K 黄；改写保护面 0 变动；改动账 N 条事件闭合；文风复检新增 M 条。

只报可复现的读数，不替读者下结论。
