# merge-overlap｜把重复段落并进被引用的那一节

## 治的判据

- 错误码：SECTION_OVERLAP
- 现象：两节之间出现大段相同或近乎相同的 8 词（英）/12 字（中）片段，默认
  重合率超过 12% 就报。判据只认字面片段，不认「意思重复」；正常引用同一
  事实但只提一句，不会触发。

## 必做

1. 先认领：同一事实只留**一个主节**。主节是第一次完整讲清它的那一节，
   后文只引用主节（`Section~\ref{...}`）或补一句本节独有的结论。
2. 本节重复的整段删掉，把本节独有的结论并进主节；不要把两段各改几个词，
   留下两份近义段落。
3. 若两节都必须保留同一组数字：主节给完整读数，另一节只给结论与指针，
   不重复列举。
4. 本节若有主节没有的解释（不同读者对象、不同条件），保留解释，删掉
   重复的事实陈述。
5. 合并后检查 `\label` / `\ref` / 交叉引用仍然指向存在的节。

## 禁做（含反例）

- 禁把重复段落改写成同义的另一段。反例：`读数从 0/12 升到 11/12。` →
  `数字由零比十二提高到十一比十二。`（片段变了，重复还在。）
- 禁为了降重合率删掉数字或引用。反例：把 `30/36` 删成「多数」——事实丢了。
- 禁把重复段落搬到相邻节（只是挪位置，重合率没降）。
- 禁删掉本节独有的结论。反例：本节结论是「顺序比工具更重要」，合并时
  只留主节的工具读数，结论消失。
- 禁把两个节合并成一个大节来绕过判据；节的结构变化要先确认标题与引用。

## 改写示例（旧 → 新）

| 旧 | 新 | 说明 |
|---|---|---|
| 讨论末节复述限制节的「已知缺口」三条，文字几乎相同。 | 讨论末节写「三个缺口见第 6.3 节；它们共同说明清洁报告只覆盖量具够得到的地方。」 | 事实指回主节，只留本节结论 |
| 两节都列 `0/12、0/8、0/12、8/12、9/12、11/12` 六个数。 | 主节保留六个数；另一节写「曲线在第 5 轮后转正（见第 5 节）」。 | 同一读数只列一次 |
| 两节都写「样本 16 单，区间 13–19 单」。 | 主节保留；另一节写「样本偏小（第 6.2 节）」。 | 数字留在主节 |

旧 → 新不删主节的事实，不删引用，不改论点。

## 验收命令

```bash
env PYTHONPATH=src python3 -m factscribe prescribe merge-overlap --json
```

改完把正文换进项目后再复核：

```bash
env PYTHONPATH=src python3 -m factscribe style <项目目录> --json
```

`SECTION_OVERLAP` 不再出现即闭合；再看 `review` 的保护面与交叉引用是否仍绿。
