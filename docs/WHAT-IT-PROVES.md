# 这工具到底证明了什么

## 先说结论

它帮你确认三件事：数字有来路，引用有出处，改写没把这两样弄坏。

它不负责证明你的结论对不对。

## 它替你挡什么

举个真实的例子。你在正文写「主对照有 16 个实例」。工具会顺着这一行往下查：

- 这一行有没有标 `\fact{A1}`；
- 账本里 A1 的值是不是 16；
- A1 钉住的那份原始产物还在不在，哈希对不对；
- 那份产物有没有人签过字。

四样缺一样，就报红。

引用也是一样的查法。你写 `\citep{nosek2018}`，它去 `refs.bib` 里找这一条，再看条目里有没有 DOI 或者 arXiv 号。找不到就红。

改写这块，它把改前和改后两个目录摆在一起逐项比：`\fact` 标记、数字、引用、公式、表格行、交叉引用。哪一样变了就报红，还告诉你在第几行变的。

## 它管不了什么

数字全对，结论照样可能是错的。这是最常见的一种误会。

它不评价的还有这些：

- 文章写得清楚还是难读；
- 审稿人会不会喜欢；
- 有没有抄别人。

它只保证一件事：**你说的数，和你的材料，对得上；你的材料，没被人偷偷换过。**

## 别人问起来，你可以这么答

> 它保证账、材料、正文三者对得上，而且材料没被改过。它不保证论文的结论是对的。

这句话可以直接用，不会被人抓话柄。

## 三句容易说错的话

| 别这么说 | 这么说 |
|---|---|
| 审计绿了，论文没问题 | 审计 0 红 1 黄，两个数字和一条引用都对上了账 |
| 新版赢了 69%，说明改得更好 | 在某个问法、某群评委下，新版被选了 69% |
| 黄牌从 42 降到 17，文章好了很多 | 触发的提示项从 42 条降到 17 条 |

这三句的区别不是措辞讲究，是**后一种说法别人能复现，前一种不能**。

## 为什么我们这么较真

两件事把我们教乖了。

第一件：同一批改写稿，换个问法，结论会翻。

- 问「哪版更像论文」，多数人选旧版；
- 改成「限定体裁，清楚和专业分开打分」，新版赢 71.7%；
- 再换个模型、把标签对调，又掉到 47.5%。

文本一个字没改。

第二件：三个评委的一致性一度算到 1.000，看着特别可靠。结果把 A/B 标签换了个位置再问，胜率掉了 16.8 个百分点。一致，不等于判得对。

所以我们现在的规矩是：**只报能复现的数，不替读者下结论。**

## 想自己验

```bash
python3 -m factscribe audit <项目>          # 账和正文对不对得上
python3 -m factscribe protect --before 旧 --after 新   # 改写有没有动硬东西
python3 -m factscribe tide --before 旧 --after 新      # 这次改动能不能闭合
```
