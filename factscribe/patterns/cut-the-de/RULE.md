# cut-the-de｜拆掉「的」链，让定语回到动词

## 治的判据

- 错误码：ZH_DE_STACK
- 现象：同一句内连续两层短修饰——相邻两个「的」间隔不超过 6 字，且至少
  两对连续成立（`弯弯的杨柳的稀疏的倩影` 是原型）。总数多、或只有一处
  短间隔（相对从句）都不算。判据（单句式，不做全文密度）见
  `docs/design/SPEC-SYNTAX.md` §2。

## 必做

1. 先找中心词：最后一个「的」后面那个名词，是这句话真正在说的东西。
2. 把中心词提到前面，让句子先说「谁是什么」，再补限定。
3. 把「的」后面的定语改写成动词句或短句：
   `A 的 B 的 C` → `C 由 B 做，B 属于 A`。
4. 一句里最多保留两个「的」；第三个起改成短句、顿号列举或动词。
5. 改写只动句法，事实、数字、条件、引用保持原样。

## 禁做（含反例）

- 禁把「的」换成另一个虚词硬撑。反例：
  `他的老师的学生的作业` → `他老师之学生的作业`（还是同一串定语）。
- 禁为了少一个「的」把定语删掉。反例：
  `最后一臂的 5/5 是一个任务的五次运行` → `最后一臂跑了五次`
  （丢掉 5/5 这个读数）。
- 禁把长定语改成括号插入语堆在名词前。反例：
  `（关于他的老师的学生的）作业`（读起来更糟）。
- 禁把一句拆成若干残句；每一句都要有自己的主谓。
- 禁改数字、编号与专名。

## 改写示例（旧 → 新）

| 旧 | 新 | 说明 |
|---|---|---|
| `这是他的老师的学生的作业的答案。` | `这份作业属于他的学生，他的学生由他的老师指导；答案是作业的。` | 把「的」链拆成主谓句（示例保留原信息，实际改写按上下文收紧） |
| `最后一臂的 5/5 是一个任务的五次运行，而不成功的那些臂是更小的集合。` | `最后一臂在 5/5 上通过；那是一个任务的五次运行。不成功的臂则是更小的集合。` | 一句拆两句，读数保留 |
| `这是一个关于规则的检查的说明的句子。` | `这个句子说明检查规则。` | 中心词提前，定语改成动词 |

旧 → 新不删数字（5/5、五次），不删限定，不删引用。

## 验收命令

```bash
env PYTHONPATH=src python3 -m factscribe prescribe cut-the-de --json
```

改完把正文换进项目后再复核（项目模式）：

```bash
env PYTHONPATH=src python3 -m factscribe style <项目> --json
```

`ZH_DE_STACK` 不再出现即闭合；只把「的」删成一个不算改完（定语仍堆在
名词前）。
