## 一、判决

RED-3 共 21 条：**采纳 16 ／部分 5 ／纯驳回 0**；另整条删除旧规则 `LEDGER_TEXT_COCHANGE`，驳回 5 个子条款（OCR 闸门、PDF 层位置归属、工具自证人签、本地私钥隔离、基线全封存）。

## 三、写死的边界（不装解决）

- 私钥必须在 agent **不可达**的机器/离线设备——**工具无法强制，也无法证明是人签**；
- 原文写死：**「若 agent 能调用签名接口，本工具在数据上无法区分人签与代签」**；
- 不做 OCR、不做渲染层 diff：图片承载定量一律红，把问题挡在源头而不是引入不可靠识别。
