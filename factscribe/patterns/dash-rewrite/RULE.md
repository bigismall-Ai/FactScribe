# dash-rewrite｜插入语破折号改写

## 治的判据

- 错误码：DASH_PARENTHETICAL
- 现象：正文用「——」或「—」插入解释、补充或限定。数值范围、页码与
  数学环境里的破折号不算。

## 必做

按顺序挑一种，不混用：

1. 去掉破折号，改成逗号引导的从属句：`A，也就是 B，仍然 C。`
2. 用括号括起插入语：`A（B）仍然 C。`
3. 拆成独立一句，补回主语句子。

三种改法都必须保留插入语承载的信息，尤其是数字、条件与限定。

## 禁做（含反例）

- 禁换成另一个破折号。反例：`结果——即 53 个样本——显著` →
  `结果 – 即 53 个样本 – 显著`（en dash 仍是插入语破折号）。
- 禁把双 hyphen `--` 当替身；排出来还是破折号。
- 禁顺手删掉插入语里的事实或数字。反例：
  `模型——在 16 次运行里都稳定——只改措辞` → `模型只改措辞`
  （丢掉「16 次运行」）。
- 禁把插入语搬到别的段落，导致指代对象丢失。

## 改写示例（旧 → 新）

| 旧 | 新 | 说明 |
|---|---|---|
| `模型——在 16 次运行里都稳定——只改措辞。` | `模型在 16 次运行里都稳定，只改措辞。` | 破折号 → 逗号从属句 |
| `读数——包括三次超时——全部留档。` | `读数（包括三次超时）全部留档。` | 破折号 → 括号 |
| `计划——它在见数据前冻结——没有改动。` | `计划没有改动；它在见数据前冻结。` | 破折号 → 拆句 |

旧 → 新不删数字（16、三次）与限定（见数据前）。

## 验收命令

```bash
env PYTHONPATH=src python3 -m factscribe prescribe dash-rewrite --json
```

改完把段落换进项目后再复核（占位符由人替换）：

```bash
env PYTHONPATH=src python3 -m factscribe style <项目> --diff <改前目录> --json
```
