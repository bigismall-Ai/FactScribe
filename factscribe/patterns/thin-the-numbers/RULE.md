# thin-the-numbers｜删掉不推进论点的数字，只留证据

## 治的判据

- 错误码：NUMERAL_DENSITY
- 现象：一段里阿拉伯数字太密（默认每千词/每千汉字超过 40 个），读者记不住，
  数字也没有推进论点。判据只数 token，不判断哪个数字有用；取舍仍由写作者做。

## 必做

1. **只在起草阶段用**：稿子还没被 `protect` 冻结时，删数字是改写；进入
   改写验收后，数字属于保护面，删数字会被 `PROTECT_NUMBER_CHANGED` 判红。
   验收阶段把项目 `style-rules.toml` 里的 `numeral_density_stage` 设为
   `"off"`，让本条降为 info。
2. 每个论点只留**一条**证据：找出这个论点靠哪个数字站住，其余数字删掉。
3. 删掉的数字若承载限定（样本量、区间、单位），改成定性说法：
   「多数」「少量」「接近一半」「在窄区间内」，不要凭空造新数字。
4. 同一事实只出现一次：前文已给过的数字，后文用「该读数」「这一比例」指回。
5. 表格与图里的数字不受本条影响；正文只保留读图必需的那几个。

## 禁做（含反例）

- 禁在改写验收阶段删数字。反例：`review --before` 已把项目判为改写验收，
  仍把 `30/36` 删成「多数」——保护面会报 `PROTECT_NUMBER_CHANGED`。
- 禁把数字换成同义的新数字。反例：`30/36` → `83%`（同一事实换皮，密度没降）。
- 禁删掉论点唯一的证据。反例：`门槛是 10/12，实测 30/36。` → `门槛已注册。`
  （论点站不住了。）
- 禁把数字改成模糊的「显著」「大幅」却不给方向。反例：`从 0/12 到 11/12`
  → `大幅提升`（读者不知道提升多少。）
- 禁为了降密度把一句话拆成三句短句——词数没降，只是把数字摊开。

## 改写示例（旧 → 新）

| 旧 | 新 | 说明 |
|---|---|---|
| `第一轮 0/12，第三轮 0/8，第四轮 0/12，第五轮 8/12，第六轮 9/12，第七轮 11/12。` | `前四轮都没抓到，从第五轮起升到 8/12 以上，第七轮是 11/12。` | 保留趋势与端点，删掉中间重复读数 |
| `样本 16 单，区间 13–19 单，均值 16.2 单，中位数 16 单。` | `样本 16 单，区间 13–19 单。` | 每个论点只留一条证据 |
| `覆盖率 83.3%，即 30/36；未覆盖 6/36，即 16.7%。` | `覆盖率 30/36。` | 同一事实只出现一次 |

旧 → 新不新增数字，不改单位，不删论点。

## 验收命令

```bash
env PYTHONPATH=src python3 -m factscribe prescribe thin-the-numbers --json
```

改完把正文换进项目后再复核：

```bash
env PYTHONPATH=src python3 -m factscribe style <项目目录> --json
```

看 `NUMERAL_DENSITY` 的读数是否回到阈值内；再看 `review` 的保护面是否仍然
全绿（改写验收阶段必须先设 `numeral_density_stage = "off"`）。
